# 七年级英语学习站 · 沪教牛津版 2026

本目录是独立的纯前端学习站点，部署在现有 GitHub Pages 项目的子路径下。

## 当前版本
- 2026 年沪教牛津版七年级上册：Unit 1—Unit 8
- 单元导航、知识讲解框架、互动练习演示、学习进度、本地保存
- 无账号、无后端、无外部依赖
- 响应式布局，支持电脑、平板和手机

## 本地预览
直接打开 `index.html`。

## 线上访问
当前仓库 GitHub Pages 部署整个仓库根目录，因此此目录发布后访问：
https://septemwuhan.github.io/math-wonderland/english-2026/

## 内容边界
当前题目是交互功能演示题，并非教材原题。教材词汇、语法、课文和同步练习将在逐课核对教材后补充。
学习记录只保存在当前浏览器 LocalStorage，不会上传服务器。
