第一章　有理数

教材第 1—23 页｜正数和负数 · 有理数及其大小比较

1.1 正数和负数

为了表示具有相反意义的量，需要引入负数。例如：零上与零下、盈利与亏损、增长与减少。

正数：大于 0 的数
负数：在正数前加“−”号的数
0 既不是正数，也不是负数。

正数前的“+”可以省略；一个数前面的“+”“−”叫作这个数的符号。

1.2.1 有理数的概念

正整数、0、负整数统称为整数；正分数、负分数统称为分数。

整数和分数统称为有理数。

有限小数和无限循环小数都可以化为分数，因此也属于有理数。正有理数、负有理数按其正负分类。

1.2.2 数轴

规定了原点、正方向和单位长度的直线叫作数轴。

数轴三要素：原点、正方向、单位长度。

数轴上的点与有理数对应。正数在原点右侧，负数在原点左侧，0 对应原点。

1.2.3 相反数

像 3 和 −3 这样只有符号不同的两个数互为相反数。

a 与 −a 互为相反数；0 的相反数是 0。
−(＋5)=−5；−(−5)=＋5。

在数轴上，互为相反数的两个点位于原点两侧，且到原点距离相等。

1.2.4 绝对值

数轴上表示数 a 的点与原点的距离，叫作数 a 的绝对值。

|a| ≥ 0；|0|=0。
a＞0 时 |a|=a；a＜0 时 |a|=−a。

互为相反数的两个数绝对值相等。绝对值表示距离，不带正负方向。

1.2.5 有理数的大小比较

在数轴上，右边的点表示的数总比左边的点大。

正数＞0＞负数
两个负数比较：绝对值大的反而小。

比较有理数大小，可以借助数轴，也可以先判断正负，再比较绝对值。

教材强调：0 是正数与负数的分界，但 0 不只是表示“没有”，例如 0℃ 和海拔 0 m 都表示一个确定的量。

例 1｜用正负数表示相反意义的量

规定超过标准质量记为正。某箱产品比标准质量多 65 g，另一箱少 30 g。
解：分别记作 +65 g、−30 g。

例 2｜有理数分类

把 −8、0、3.5、−12%、7、−2.4 分类。
解：正有理数：3.5、7；负有理数：−8、−12%、−2.4；整数：−8、0、7。

例 3｜数轴与相反数

数轴上表示 −3 的点与原点相距 3 个单位。与它互为相反数的数是 +3，对应点在原点右侧 3 个单位处。

例 4｜绝对值与大小比较

比较 −5 与 −2：因为 |−5|=5，|−2|=2，且 5＞2，所以 −5＜−2。
易错提醒：① 0 既不是正数也不是负数；② 相反数是“符号相反”，绝对值是“到原点的距离”；③ 负数比较大小时，不能只看数字部分的大小。

本章知识主线

引入负数 → 扩大数的范围到有理数 → 用数轴表示有理数 → 认识相反数和绝对值 → 比较有理数大小。

关键数学思想

数形结合：数轴把数与点对应起来。分类讨论：按正数、负数、0，或整数、分数等不同标准分类。

自我检查

  • 能否用正负数表示相反意义的量？
  • 能否正确分类有理数？
  • 能否规范画数轴并表示数？
  • 能否求相反数、绝对值并比较大小？

第二章　有理数的运算

教材第 24—62 页｜加法与减法 · 乘法与除法 · 乘方

2.1 有理数的加法与减法

加法：同号两数相加，取相同符号，并把绝对值相加；异号两数相加，取绝对值较大的加数的符号，并用较大的绝对值减去较小的绝对值；互为相反数相加得 0；一个数同 0 相加仍得这个数。

a−b = a＋(−b)
减去一个数，等于加这个数的相反数。

加法交换律：a+b=b+a；加法结合律：(a+b)+c=a+(b+c)。

2.2.1 有理数的乘法

两数相乘，同号得正，异号得负，并把绝对值相乘。
任何数与 0 相乘，积为 0。

多个不为 0 的数相乘，负因数个数为偶数时积为正，奇数时积为负；有因数为 0，积为 0。

乘法交换律、结合律仍成立；乘法对加法满足分配律。

ab=ba；(ab)c=a(bc)
a(b+c)=ab+ac

2.2.2 有理数的除法

除以一个不等于 0 的数，等于乘这个数的倒数。
a÷b=a×(1/b)，b≠0。

两数相除，同号得正，异号得负，并把绝对值相除；0 除以任何一个不等于 0 的数都得 0。

2.3.1 有理数的乘方

求 n 个相同因数 a 的积的运算，叫作乘方。乘方的结果叫作幂，a 叫作底数，n 叫作指数。

aⁿ = a×a×…×a（n 个 a）
读作“a 的 n 次方”。

注意区分 (−2)² 与 −2²：前者底数是 −2，后者的底数是 2，负号在乘方运算之外。

2.3.2 科学记数法

把一个大于 10 的数表示成 a×10ⁿ 的形式，其中 1≤|a|＜10，n 为正整数。

例如：3 000 000 = 3×10⁶。指数表示 1 后面有多少个 0（对整数情形）。

2.3.3 近似数

与准确数接近、但不完全等于准确数的数叫作近似数。近似程度通常用精确度表示。

按四舍五入法：π≈3.14（精确到百分位）。

表示近似数时，末尾的 0 可能表示精确度，不能随意省略。

运算总原则：先确定符号，再处理绝对值；混合运算要先乘方，再乘除，最后加减；有括号时先算括号里面。

例 1｜有理数加法

(−8)+(+3)
解：异号两数相加，取绝对值较大的加数 −8 的符号，并用 8−3=5，结果为 −5。

例 2｜减法转化为加法

5−(−7)
解：5+(+7)=12。

例 3｜多个数相乘

(−2)×3×(−4)
解：有两个负因数，积为正；绝对值为 2×3×4=24，所以结果为 24。

例 4｜乘法分配律

8×(−99)
解：8×(−100+1)=−800+8=−792。

例 5｜乘方

(−3)²=9；−3²=−9。
关键：括号决定底数是否包含负号。

例 6｜混合运算

2＋(−3)²×(−2)
解：先乘方得 9，再乘法得 −18，最后 2+(−18)=−16。
易错提醒：① 减去负数要转化为加正数；② 乘法中负因数个数决定积的符号；③ 除数不能为 0；④ −a² 与 (−a)² 通常不同；⑤ 近似数 1.80 与 1.8 的精确度不同。

运算体系

加法与乘法是基本运算；减法是加法的逆运算，除法是乘法的逆运算（除数不为 0）；乘方是求几个相同因数的积。

运算律

加法交换律、结合律；乘法交换律、结合律、分配律。合理使用运算律可以简化计算。

教材强调的思想方法

数系扩充、运算一致性、数形结合与转化。与负数有关的运算，常借助绝对值转化为正数之间的运算。

第三章　代数式

教材第 68—85 页｜3.1 列代数式表示数量关系 · 3.2 代数式的值

3.1 列代数式表示数量关系

用运算符号把数或表示数的字母连接起来的式子叫作代数式。单独的一个数或一个字母也是代数式。

总价＝单价×数量；路程＝速度×时间；长方形面积＝长×宽。

数字通常写在字母前；数字与字母相乘，乘号通常省略。相同字母相乘可写成幂，如 a·a=a²。

列式与运算顺序

先分析题意中的数量关系，再确定运算顺序，必要时使用括号。

a 与 b 的和的 2 倍：2(a+b)
a 的 2 倍与 b 的和：2a+b

正比例与反比例

工作效率一定时，工作量与工作时间成正比例；工作量一定时，工作时间与工作效率成反比例。

正比例：y=kx（k≠0）
反比例：xy=k（k≠0）

3.2 代数式的值

用具体数值代替代数式里的字母，按照代数式指明的运算计算所得结果，叫作代数式的值。

当 a=2 时，3a+1=3×2+1=7。

代入负数时通常加括号，注意运算顺序。

易错提醒：2(a+b) 与 2a+b 不相同；代入负数时要注意括号；同一问题中的同一字母表示同一个量。

例 1｜列代数式

苹果每千克 p 元，买 3 kg，另付包装费 2 元。总费用为 3p+2 元。

例 2｜注意运算范围

a、b 两数的和与差的积：(a+b)(a−b)。

例 3｜代数式求值

当 x=−2 时，x²+3x−1=4−6−1=−3。

例 4｜正比例关系

每小时行驶 60 km，行驶 t 小时的路程为 60t km。

本章主线

分析数量关系 → 列代数式 → 理解字母表示的一般性 → 代入求值。

检查清单

能列式、能读懂代数式、能正确代入负数、能识别正比例与反比例关系。

第四章　整式的加减

教材第 88—107 页｜4.1 整式 · 4.2 整式的加法与减法

4.1 单项式

数与字母的积组成的代数式叫作单项式，单独一个数或字母也是单项式。单项式中的数字因数叫作系数，所有字母的指数和叫作次数。

−3x²y 的系数为 −3，次数为 2+1=3。

多项式与整式

几个单项式的和叫作多项式。每个单项式叫作多项式的项，不含字母的项叫常数项。单项式与多项式统称整式。

2x²−3x+5 的项为 2x²、−3x、5；次数为 2。

同类项

所含字母相同，并且相同字母的指数也分别相同的项叫作同类项。所有常数项都是同类项。

3x²y 与 −5x²y 是同类项；2x 与 2x²不是。

4.2 合并同类项

把同类项的系数相加，所得结果作为系数，字母和字母的指数不变。

3a+5a=(3+5)a=8a

去括号与整式加减

括号前是“+”号，括号内各项符号不变；括号前是“−”号，括号内各项符号改变。整式加减通常先去括号，再合并同类项。

(2x+3)−(x−5)=x+8
易错提醒：次数是字母指数的和；同类项必须字母相同且指数对应相同；括号前的负号要改变括号内每一项的符号。

例 1｜判断次数

单项式 4a²b³ 的次数为 2+3=5，系数为 4。

例 2｜合并同类项

5x−2x+3x=(5−2+3)x=6x。

例 3｜去括号

3a−(2a−b)=3a−2a+b=a+b。

例 4｜整式加减

(2x²+x−1)−(x²−3x+2)=x²+4x−3。

本章主线

认识整式 → 判断系数、次数、项 → 识别同类项 → 去括号 → 合并同类项。

检查清单

会求单项式和多项式次数；会识别同类项；会正确去括号和合并同类项。

第五章　一元一次方程

教材第 110—145 页｜5.1 方程 · 5.2 解一元一次方程 · 5.3 实际问题与一元一次方程

5.1 方程

含有未知数的等式叫作方程。使方程左、右两边相等的未知数的值叫作方程的解。

一元一次方程：只含一个未知数，未知数次数为 1，且等号两边都是整式。

等式的性质

两边同时加（或减）同一个数或式子，等式仍成立。
两边同时乘同一个数，或除以同一个不为 0 的数，等式仍成立。

5.2 解一元一次方程

常用步骤：去分母、去括号、移项、合并同类项、系数化为 1。移项时要改变符号。

ax+b=c（a≠0）
先移项、合并同类项，再系数化为 1。

5.3 实际问题与一元一次方程

常见情境有行程、工程、商品销售、利润、配套、分配和数字问题。关键是分析题意，找出相等关系。

路程＝速度×时间
工作量＝工作效率×时间
利润＝售价−进价

列方程的一般步骤

审题，找出未知量；设未知数；根据数量关系列方程；解方程；检验解是否符合实际；写出答案。

易错提醒：移项要变号；去分母时方程两边每一项都要乘公分母；实际问题要检查单位和答案的合理性。

例 1｜解方程

3x−5=10。解：3x=15，x=5。

例 2｜含括号方程

2(x−3)=x+1。解：2x−6=x+1，x=7。

例 3｜行程关系

两地相距 120 km，速度为 60 km/h，设时间为 x，则 60x=120，x=2 h。

例 4｜利润关系

进价 80 元，按进价提高 25% 定价，售价为 80(1+25%)=100 元。

本章主线

实际问题 → 数量关系 → 一元一次方程 → 等式性质与运算 → 检验 → 实际答案。

检查清单

能识别一元一次方程；理解等式性质；会解含括号、分母的方程；能从实际问题中找相等关系。

第六章　几何图形初步

教材第 149—184 页｜6.1 几何图形 · 6.2 直线、射线、线段 · 6.3 角

6.1 几何图形

几何图形分为立体图形和平面图形。长方体、正方体、圆柱、圆锥、球是立体图形；线段、角、三角形、圆是平面图形。

从不同方向观察立体图形，可能看到不同的平面图形；立体图形的表面展开图有助于认识其结构。

点、线、面、体

几何体由面围成，面与面相交形成线，线与线相交形成点。点动成线、线动成面、面动成体。

6.2 直线、射线、线段

两点确定一条直线。
两点之间，线段最短。

直线向两方无限延伸；射线有一个端点，向一方无限延伸；线段有两个端点，长度有限。

线段的比较与中点

比较线段长短可用度量法或叠合法。点 M 把线段 AB 分成相等两段时，M 是 AB 的中点。

AM=MB=½AB；AB=AM+MB

6.3 角

有公共端点的两条射线组成的图形叫作角。公共端点是顶点，两条射线是角的边。

1 周角=360°；1 平角=180°
1°=60′；1′=60″

角的比较与运算

角的大小可以用度量法或叠合法比较。角平分线把一个角分成两个相等的角。

若 OC 在 ∠AOB 内部：
∠AOC+∠COB=∠AOB

度、分、秒分别运算，满 60 进 1。

易错提醒：直线、射线不能度量长度；线段有两个端点；角的顶点字母写在中间；角度的分、秒是六十进制。

例 1｜图形分类

圆柱、圆锥、球属于立体图形；三角形、圆、角属于平面图形。

例 2｜线段中点

若 M 是 AB 的中点，AB=10 cm，则 AM=MB=5 cm。

例 3｜线段和

AB=8 cm，BC=3 cm，且 B 在线段 AC 上，则 AC=8+3=11 cm。

例 4｜角度换算

35°=2100′；2°30′=150′。

例 5｜平角关系

A、O、B 在一条直线上，∠AOC=53°17′，则 ∠BOC=180°−53°17′=126°43′。

本章主线

认识几何图形 → 研究直线、射线、线段 → 比较和计算线段长度 → 认识角并进行度量、比较与运算。

检查清单

能区分立体图形和平面图形；掌握直线、射线、线段特征；会用中点关系求长度；会读写角并进行度分秒换算。
